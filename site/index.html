Hardware

        
One engine, from a laptop iGPU to four Pro B60s. The same Qwen3.8 27B file on every machine.

      

      
The engine was built and tuned on a Core Ultra 5 125H, which has no matrix engines. Where a GPU has XMX, the prompt's matrix products move onto it after a start-up check against the DP4a kernels. One model can be split over several cards with --gpus N.

What it does

        
Built for long documents and coding agents. On hardware that was never meant for it.

      

      
An OpenAI-, Anthropic- and Ollama-compatible server with a web UI, in one 8 MB download. No compiler, no Python, no CUDA.

    

    

      

        
Mixture of experts

        
Models larger than the GPU's memory

        
Only the experts in use stay in GPU memory. The next layer's missing experts are read from the SSD while the GPU computes the current one, so Flash Next's 52 GB of experts run on a 32 GB laptop. The launcher can pack such a model so its experts are stored once, not twice: Gemma 4 26B takes 14.8 GB instead of 27.7.

Speculative decoding

        
Faster generation, the same answer

        
The model's own MTP block and a DFlash2 drafter guess up to 7 tokens; the full model checks them in one pass. Accepted drafts are the tokens plain decoding would have picked.

        

          def get(self, key): node = self.cache self._map.get(key)
        

        
35B, coding answer21.6 → 38.1 tok/s
27B on one B6023.2 → 49.3 tok/s

      

      

        
Deterministic

        
The same logits, bit for bit

        
Run after run, whatever the expert cache size. Every speed change is held to that, or to a measured KL below 0.015.

      

      

        
Caches

        
Conversations that do not start over

        
A new message only processes itself. After a 20K-token tool result, a one-line follow-up on Gemma 4 E4B takes 0.8 s instead of 38 s.

      

      

        
Documents

        
Long files, read properly

        
Whole when the context takes it, else by outline, pages or search. OCR turns scanned PDFs into Markdown, tables as tables. Answers name their page.

      

    

  







  

    

      

        
Web UI

        
A chat that searches, reads and listens. At 127.0.0.1:8090, or from your phone.

      

      
The server ships its own web UI: chats with files and projects, web search, a voice conversation, and tabs for transcripts and meetings. Through a Cloudflare Tunnel with a password it works from anywhere, installable as an app.

For agents

        
Speaks the APIs your tools already use. Plugs into Pi with one command.

      

      
Prompt and session caches mean an agent's growing context is processed once. Tool calls are constrained to their JSON schema while they are sampled, so they stay well formed. Two sessions can share one model, their tokens computed in the same pass.

Discrete Arc · experimental

        
Arc B-series cards, one or four. Tuned from users' measurements.

      

      
B580, Pro B60 and Pro B70 run the same engine with switches of their own that the iGPUs never take. Their speed comes from people who own the cards and post their runs; every default for them was set from those numbers.

    

    

      

        
XMX

        
Prompts on the matrix engines

        
The prompt GEMMs run as int8 DPAS, checked bit for bit against DP4a at start. H8 rotations with 4 column groups took the 27B from 766 to 1,024 tok/s at 4K.

      

      

        
Tensor parallel

        
One model over several GPUs

        
--gpus N splits the 27B or the 35B by heads and columns. A GPU that hangs makes the request fail and /health answer 503; the server stays up.

      

      

        
Measure yours

        
Scripts that report back

        
bench\website_bench.ps1, decode_try.ps1 and f33_sweep.ps1 print everything needed. Post the output on issue #4.

      

    

  







  

    

      

        
Get started

        
Three steps, about five minutes. Plus the model download.

      

      
The launcher ticks the model that suits your RAM, downloads it with resume and a checksum, and opens the web UI when the server is ready.

    

    

      
Download
Get inferzero-<version>-win64.zip from the latest release and unpack it anywhere.

      
Start
Double-click zero-launcher.cmd. Windows may ask once: "More info", then "Run anyway".

      
Pick a model
Choose one and press "Download and start". The web UI opens at 127.0.0.1:8090.

    

    

      
SystemWindows 11, 64-bit, with Intel's graphics driver.

      
GPUCore Ultra with Arc graphics (Meteor Lake, Lunar Lake, Arrow Lake H, Panther Lake), or an Arc B-series card.
